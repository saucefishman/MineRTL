# Examples

Build any of these with `./synth.sh examples/<name>`. Each directory holds the Verilog (top module `main`), and a
`pin_targets.json` where the outputs should land somewhere specific.

## Getting started

| Example | Shows |
| --- | --- |
| `helloworld` | One gate (`y = a ^ b`): the smallest build, combinational logic only. |
| `counter` | A 4-bit counter: flip-flops, an adder, and the generated clock on `clk`. |
| `multimodule` | A 4-bit ripple-carry adder from four `full_adder` instances: module hierarchy and buses. |
| `sevenseg` | A decimal counter on a seven-segment display: `case` decoding, and `pin_targets.json` placing the outputs as a display. |
| `printing` | `$write`/`$display` debug prints: prints "Hello!" and a lap count, shown by MCHPRS `/watch` or `mchprs_headless test --probes`. |

## Memories

| Example | Shows |
| --- | --- |
| `regs` | A 4-word register file: a Verilog memory built from flip-flops. |
| `ramtile` | The smallest memory that becomes a tiled RAM block with `--tiled-ram` (2 reads, 1 write). `scripts/check_ram.py` tests it against a model. |
| `memread` | A memory loaded with `$readmemh` and read out in order. `scripts/check_memread.py` runs it. |
| `preload` | Two preloaded tiled memories on shared addresses, read back before any write. `scripts/check_preload.py` runs it. |

## Regression designs

Small circuits kept because an acceptance script builds them.

| Example | Shows |
| --- | --- |
| `powerup` | Flip-flops that keep their initial values at power-up only when the build is settled (`--no-settle` loses them on `--place-seed 7`). `scripts/check_powerup.py`. |
| `powerup_inverted` | Clocks that rest high at power-up: settling has to keep every initial value. `scripts/check_powerup.py`. |
| `bpmem` | floweypu's branch predictor memories on their own. `scripts/check_bpmem.py`. |

## Showcases

Large designs. They take minutes to build, so `scripts/bench_examples.py` skips them unless named.

| Example | Shows |
| --- | --- |
| `cpu` | A 16-bit CPU (see `cpu/readme.txt` for its instructions) running a program preloaded from `prog.hex`. Repeated subcircuits become macros. |
| `video` | A 16x12 frame buffer loaded 8 bits at a time, its outputs laid out as a screen by `pin_targets.json`. |
| `floweypu` | A pipelined CPU with a branch predictor, from SystemVerilog (`make` runs `sv2v`). About 12,600 nets; build with `--tiled-ram --no-macros`. See `docs/floweypu_build.md`. |
| `floweypu_hi` | floweypu with a ROM that prints 1, 2, 3, then `hi`. `scripts/check_floweypu.py` runs it. |
| `floweypu_loop` | floweypu with a looping program that works the branch predictor (generated by `floweypu/test/loop_asm.py`). |
